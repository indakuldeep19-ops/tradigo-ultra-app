# Tradigo Ultra V4.0 🤖📈

AI-Powered Multi-Exchange Crypto Trading Ecosystem

![Logo](docs/logo.png)

## Features
- 🔐 Secure Login & OTP Verification
- 📊 Real-time Trading Dashboard
- 🤖 Jarvis AI Assistant
- 👥 Duo Trading (Trade with Friends)
- 💰 Wallet & Razorpay Payments
- 🎓 Crypto University
- 🏆 Leaderboards & Rewards
- 📰 AI News Hub

## Tech Stack
- **Frontend:** Kotlin + Jetpack Compose
- **Backend:** Firebase Cloud Functions + Express
- **Database:** Firestore + Redis
- **AI:** Google Gemini API
- **Payments:** Razorpay
